> Этот документ изначально был написан как самостоятельный бриф для отдельной сессии Claude Code и переложен в `docs/` как актуальное ТЗ на Фазу 1, дополняющее `docs/tz-development.md` дизайн-частью. Общий контекст проекта, роли агентов и правила координации — в [`CLAUDE.md`](../CLAUDE.md). Трекер задач и статусы — в [`docs/priorities.md`](priorities.md). Пункты раздела 5 этого документа — те же находки аудита, что и в `docs/priorities.md` (P0 №1–4, P1 №5–9), только объединены с дизайн-требованиями в одну волну работ.

## 0. Что это за проект

Интернет-магазин стройматериалов и хозтоваров **casa24.md** (торговая марка «Meșterul Casei», юрлицо «LAROMVAL» SRL, Кишинёв, Молдова). Сайт работает на **WordPress + WooCommerce**, тема Glozin / glozin-child, конструктор Elementor, мультиязычность **WPML (RU + RO)**, оплата — плагин maib (`maib-checkout-payment-gateway-for-woocommerce`), SEO-плагин **Rank Math**, также установлены Contact Form 7 и Jetpack. Каталог товаров синхронизируется из внешней 1С-учётной системы (отдельный механизм обмена, вне рамок этой задачи — не трогать).

Сайт запущен недавно, наработанной клиентской базы и SEO-истории пока нет — можно вносить изменения без страха «сломать репутацию», но нельзя ломать работающий приём заказов и оплату.

## 1. Цель Фазы 1

Быстро обновить внешний вид сайта на профессиональный, современный дизайн («Industrial Pro», спецификация ниже) и исправить конкретные содержательные и технические ошибки — чтобы после этого сразу перейти к SEO-продвижению и приёму заказов. **Скорость важнее полноты** — в эту фазу сознательно не входит ничего из раздела 6 «Не входит в объём работ».

## 2. Обязательные ограничения по безопасности

- **Никогда не вводить пароли в формы логина** — ни основной пароль администратора WordPress, ни временный, ни какой-либо ещё, даже если пользователь сам его пришлёт и разрешит. Это правило действует всегда.
- Все изменения сначала делаются и проверяются **на staging-копии** сайта (или в локальном/тестовом окружении с копией темы и тестовой базой), и только после проверки владельцем выкатываются на прод. Если staging недоступен — работать только с файлами темы (создание/правка файлов кастомной дочерней темы), не трогая рабочую БД и не выполняя необратимых операций на проде.
- Если для работы нужен программный доступ к сайту — это **WordPress Application Password** (создаётся в Пользователи → Профиль → Application Passwords), а не основной пароль. Токен передаётся владельцем через переменные окружения/секреты, не хранится в коде и не публикуется в git.
- Не трогать: настройки оплаты maib, механизм обмена с 1С, учётные записи пользователей/клиентов, существующие заказы.
- Любые необратимые или публикующие действия на проде (публикация, изменение настроек аккаунта, удаление чего-либо) — только с явного подтверждения владельца сайта.

## 3. Технический подход

- Платформа остаётся **WordPress + WooCommerce** — не переезжаем на другой стек.
- Визуал реализуется **кастомной дочерней темой** (child theme) с собственной разметкой и CSS/PHP-шаблонами — **не через Elementor-конструктор** и не через сборку из готовых блоков. Цель — уйти от вида «шаблонного» сайта.
- Структура и функциональность существующих страниц сохраняются (список ниже, по акту сдачи сайта) — меняется оформление и вёрстка, а не набор функций:
  - Главная страница с блоками: слайдер/логотип, «Наши преимущества», «Категории товаров», «Топ продаж», бегущая строка, «Популярные товары», «Отзывы клиентов», «О нас».
  - Страницы: Контакты, О нас, Статьи, Корзина, Оформление заказа, Личный кабинет, Избранное, Доставка и оплата.
  - Карточка товара: возможность поделиться, добавить в избранное, отзывы, похожие товары, недавно просмотренные, быстрый просмотр, добавление в корзину, онлайн-оплата, форма заявки на странице товара.
- Мультиязычность (WPML, RU/RO) должна продолжать работать на обеих языковых версиях после редизайна — проверить оба языка перед сдачей.
- Мета-теги (title/description) и Open Graph — через уже установленный **Rank Math**, не изобретать отдельный механизм.
- Адаптивность: сайт должен корректно выглядеть на мобильных и планшетах — исходный дизайн-макет рассчитан на десктоп (1280px), адаптируйте под мобильную сетку по стандартным брейкпоинтам.

## 4. Дизайн-спецификация — направление «Industrial Pro»

Тёмная шапка/хиро с оранжевым акцентом — читается как «настоящий строительный магазин», ориентир по уровню — Supraten.md, Dedeman.ro, Leroy Merlin România (не копировать, а соответствовать уровню опрятности и профессионализма). Кастомный логотип (иконка дома/ящика с инструментами + двухстрочный воркмарк) заменяет текущий логотип «Larom Val» (см. раздел 5, пункт 1 — это одна из главных проблем текущего сайта).

### 4.1 Цветовые токены (CSS custom properties, значения в oklch)

```css
:root{
  --bg-dark: oklch(0.20 0.02 255);      /* тёмный фон шапки/хиро/футера */
  --bg-dark-2: oklch(0.27 0.02 255);    /* верхняя тонкая утилити-полоса, вторичный тёмный фон */
  --accent: oklch(0.70 0.19 45);        /* фирменный оранжевый — акценты, кнопки, цены */
  --accent-dark: oklch(0.52 0.17 45);   /* оранжевый для текста на светлом фоне (цены в карточках) */
  --bg-light: oklch(0.985 0.004 90);    /* фон страницы */
  --surface: oklch(1 0 0);              /* карточки/плашки на светлом фоне */
  --border: oklch(0.90 0.005 90);       /* тонкие разделители */
  --text: oklch(0.24 0.01 255);         /* основной текст */
  --text-muted: oklch(0.50 0.01 255);   /* вторичный текст */
  --on-dark: oklch(0.97 0.005 90);      /* текст на тёмном фоне */
  --on-dark-muted: oklch(0.72 0.01 255);/* вторичный текст на тёмном фоне */
}
```

### 4.2 Типографика

- Заголовки (h1–h3, названия категорий, цены, кнопки, навигация) — **Barlow Condensed**, начертания 600/700, `text-transform: uppercase`, `letter-spacing: 0.01–0.04em`.
- Основной текст (параграфы, названия товаров в карточках) — **Work Sans**, начертания 400/500/600.
- Шрифты подключаются через Google Fonts: `Barlow Condensed:wght@600;700` и `Work Sans:wght@400;500;600`.

> **Изменение 25.10.2026 (решение владельца):** вместо Barlow Condensed используется **Roboto Condensed** (600/700). В Barlow Condensed нет кириллицы — на staging все русские заголовки выводились запасным шрифтом. Roboto Condensed близок по характеру и поддерживает и кириллицу, и румынские ș/ț/ă. Везде ниже, где написано «Barlow Condensed», читать «Roboto Condensed».

### 4.3 Кнопки

- `.btn-accent`: фон `--accent`, текст тёмный (`oklch(0.15 0.02 255)`), без рамки, шрифт Barlow Condensed 700, uppercase, `border-radius: 2px`, паддинг `14px 26px`.
- `.btn-outline`: прозрачный фон, текст `--on-dark`, рамка `2px solid var(--on-dark)` — используется на тёмном фоне (хиро).

### 4.4 Структура главной страницы (сверху вниз)

1. **Утилити-полоса** (фон `--bg-dark-2`, мелкий текст `--on-dark-muted`): слева телефон и e-mail, справа — «Доставка и оплата / О нас / Контакты».
2. **Шапка** (фон `--bg-dark`): слева — логотип-иконка + воркмарк «MEȘTERUL CASEI» / «CASA24.MD» (вторая строка — оранжевым, letter-spacing 0.18em); по центру — навигация (Каталог, Двери, Электроинструмент, Сад и огород, Статьи) шрифтом Barlow Condensed uppercase; справа — иконки поиска, избранного, корзины (с оранжевым бейджем-счётчиком).
3. **Хиро** (фон `--bg-dark`, две колонки ~58%/42%): слева — короткая оранжевая плашка-акцент, заголовок H1 (58px, тесный line-height, ключевая фраза выделена оранжевым), короткий подзаголовок, кнопки «Смотреть каталог» (accent) + «О компании» (outline), под ними — строка с УТП (бесплатная доставка от 1000 MDL, гарантия качества). Справа — сетка 2×2 из кликабельных категорий-плашек с разными тёмными оттенками фона, иконкой и подписью.
4. **Категории** (светлый фон): заголовок H2 «Категории» + ссылка «Все категории», ниже сетка из 4 карточек (иконка в тёмном квадрате-бейдже, название Barlow Condensed uppercase, короткое описание `--text-muted`).
5. **Товары** («Топ продаж» и, ниже, отдельно «Популярные товары» — **с разным содержимым**, см. раздел 5): заголовок H2 + «Смотреть всё», сетка из 4 карточек: фото/иконка-плейсхолдер, название (Work Sans, 2 строки), цена (Barlow Condensed 700, `--accent-dark`) и тёмная квадратная кнопка «в корзину» с оранжевой иконкой.
6. **Блок «Товары на скидках»** (уже реализован вместо «Популярных товаров», 19.09.2026): без таймера обратного отсчёта и формулировок «Flash sale» — только реальные акционные цены из WooCommerce (решение 27.10.2026). Доработки: если товаров со скидкой нет — блок целиком скрывается (сейчас покупателю показывается служебная фраза «Сейчас нет товаров со скидкой…»); ссылка «Смотреть всё» ведёт на список именно акционных товаров, а не на весь магазин. Кто и как регулярно заводит акции — решается с директором отдельно.
7. **Футер**: тёмная полоса с воркмарком слева и копирайтом справа; в реальной теме — полноценный футер сайта (контакты, ссылки, соцсети), эта плашка — только нижний акцентный слой в стиле хиро/шапки.

Ссылка на кликабельный референс дизайна и общий контекст обсуждения — в проектной документации (`casa24-redesign-plan.md`, `casa24-audit.md` в связанном Claude-проекте «Магазин»); при необходимости запросите эти файлы у владельца сайта.

## 5. Обязательные исправления из аудита (входят в объём Фазы 1)

Полный аудит доступен по запросу; ключевые пункты, которые нужно закрыть в этой же волне работ (соответствие нумерации в `docs/priorities.md` указано в скобках):

1. **Брендинг** (priorities P0 №1): заменить логотип и favicon «Larom VAL» (`cropped-Laromval-ICO-32x32.webp`) на новый логотип «Meșterul Casei» / Casa24 (см. раздел 4.4, п.2) везде — шапка, favicon, все упоминания в футере должны быть согласованы.
2. **Неверная цена** (priorities P0 №2): товар «Дверь межкомнатная Model R14» стоит 1,00 MDL вместо ожидаемых ~2 100–2 900 MDL (как у аналогичных дверей). Исправить цену, дополнительно пройтись по каталогу дверей на предмет похожих аномалий. *27.10.2026: в 1С исправлено, RU-версия — 2 700 MDL, но RO-версия всё ещё 1,00 MDL — цены из 1С не синхронизируются в RO-переводы, подробности в `docs/priorities.md`, п. 2.*
3. **Дублирующиеся блоки** (priorities P0 №4 / P1 №6): «Топ продаж» и «Популярные товары» на главной показывают одинаковый список из 10 товаров в одном порядке — должны быть разные подборки (например, по продажам vs по просмотрам). Также убрать дублирование блоков категорий/отзывов, повторяющихся 2–3 раза подряд в HTML (похоже на баг карусели/Swiper без корректной разметки дублей-слайдов).
4. **Meta description и Open Graph** (priorities P0 №3): заполнить через Rank Math для главной страницы и ключевых категорий на обоих языках (RU/RO).
5. **Отсутствующее фото товара** (priorities P1 №5а): у «Clasica KN SS 70 G со стеклом» (первая позиция в категории «Двери») нет фото — заменить на реальное изображение или временный плейсхолдер в едином стиле карточки товара.
6. **Непереведённые отзывы** (priorities P1 №7): в блоке «Recenzii ale clienților» на румынской версии тексты отзывов остались на русском — перевести на румынский.
7. **Alt-теги** (priorities P1 №5): часть изображений на главной без атрибута `alt` — добавить осмысленные alt-тексты (SEO + доступность).
8. **Опечатки в названиях товаров** (priorities P1 №9): «Дверь металичческая» → «металлическая», «oreh» → «орех», лишние звёздочки в конце названий («Model KM01 880*2050*», «Укрывные материалы и защита от солнца*»), артикул вместо названия в меню («Сверло по металлу 5555555») — пройтись по каталогу и почистить.
9. **robots.txt** (priorities P2 №13): убрать дублирующуюся директиву `User-agent: *`.
10. **wp-sitemap-users** (priorities P1 №8): отключить публичную карту сайта авторов (раскрывает логины пользователей).
11. **Структура языковых URL** (priorities P2 №11): унифицировать адреса RU/RO-версий (сейчас hreflang заявляет `/ro/`, но фактические ссылки ведут то на `casa24.md/` без префикса, то на `/ru/all-categories/`) — единый предсказуемый паттерн для обеих версий, чтобы не плодить дубли в индексе Google.

Это не полный список из аудита — остальное (снижение числа запросов/веса главной страницы, TTFB, ревизия плагинов) можно делать по мере ресурсов уже после запуска обновлённого дизайна, не обязательно в первой волне.

## 6. Не входит в объём работ (Фаза 2 — отдельная задача, не начинать без явного запроса)

- ИИ-чат-помощник подбора товара, умный поиск по смыслу, визуальный поиск по фото, сопутствующие товары по задаче, голосовой аватар-помощник.
- Автоматизированный конвейер обработки карточек товара из 1С (AI-генерация названий/описаний на RU+RO, очередь на проверку, автообработка фото от бликов).
- Глоссарий молдавских терминов для румынской генерации.
- Любые изменения механизма обмена с 1С.
- Переход на другую платформу/параллельная сборка нового сайта — решено остаться на текущем WordPress-сайте.

## 7. Процесс работы

1. Подтвердить у владельца сайта: доступен staging (или его аналог), способ доступа (Application Password и/или файлы под ключ для ручной загрузки), название хостинга — **на момент старта работы над этим ТЗ (19.09.2026) доступ ещё не подтверждён, поэтому первая волна работ ведётся только с файлами дочерней темы в этом репозитории, без подключения к боевой базе.**
2. Разработать дочернюю тему и все правки из раздела 5 локально/на staging, с git-историей изменений.
3. Проверить на staging: обе языковые версии (RU/RO), десктоп и мобильная раскладка, весь путь оформления заказа до оплаты (в тестовом режиме maib, если доступен тестовый контур; иначе — не завершать реальный платёж), корректность работы Rank Math мета-тегов, отсутствие ошибок в консоли браузера.
4. Показать staging владельцу для приёмки перед выкаткой на прод.
5. Выкатка на прод — только после подтверждения, самим владельцем или по его прямому запросу с пониманием, что это последний необратимый шаг.

## 8. Критерии приёмки

- Все 11 пунктов раздела 5 исправлены и проверены.

- Обе языковые версии (RU/RO) работают корректно, без потери переводов.
- Мобильная версия не ломается (проверить минимум 375px и 768px ширины).
- Ни один пароль/секрет не закоммичен в git и не введён в форму логина в процессе работы.
