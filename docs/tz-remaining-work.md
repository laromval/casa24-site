## 1. Общие правила для всех работ

1. Сначала staging, проверка, приёмка владельцем — потом рабочий сайт.
2. Любое изменение, видимое покупателю (цены, каталог, тексты), — через content-agent с проверкой qa-agent.
3. Пароли, ключи, токены не попадают в репозиторий и не вводятся Claude в формы; пароли вводит владелец.
4. Каждое изменение — коммит в ветку с понятным описанием; на рабочий сайт уходит только то, что смержено в `main`.
5. Для каждого изменения рабочего сайта заранее описан способ отката.

## 3. Безопасность — приоритет 1, срок 30.10.2026

### 3.1. Смена паролей (24)
Пароль администратора WordPress уже сменён 26.10.2026. **Осталось:**
- **Пароль базы данных** — сменить в cPanel («Базы данных MySQL») и одновременно в `wp-config.php` (`DB_PASSWORD`); надёжнее — попросить поддержку TopHost сделать обе правки сразу.
- **Ключи и соли WordPress** — заменить в `wp-config.php` новыми (генератор api.wordpress.org/secret-key); все пользователи выйдут из аккаунтов.
- **Пароль cPanel** — «Пароли и безопасность» в cPanel; «последний вход» был с IP подрядчика.

**Критерии приёмки.** Сайт работает после каждой смены; вход в админку и cPanel — только по новым паролям; пароли сохранены у владельца, не в репозитории.

### 3.2. Журнал ошибок (25)
`wp-content/debug.log` — 2,3 ГБ на проде (и копия на staging), включён `WP_DEBUG_LOG`. Выключить запись в журнал на рабочем сайте (`WP_DEBUG_LOG = false` в `wp-config.php`), удалить файл.
**Критерий.** Файла нет, место на диске освободилось, сайт работает.

### 3.3. Просмотр списка файлов (20)
Папки темы открываются как список файлов. Добавить `Options -Indexes` в `.htaccess` сайта (или настройку в cPanel → «Индексы»).
**Критерий.** `https://casa24.md/wp-content/themes/glozin-child/` отдаёт 403, а не список.

### 3.4. robots.txt (13)
Убрать дублирующуюся директиву `User-agent: *` — сначала выяснить источник (физический файл или Rank Math), см. `wp-content/themes/glozin-child/TODO-industrial-pro.md`.
**Критерий.** Одна группа `User-agent: *`; проверка в Google Search Console без ошибок.
