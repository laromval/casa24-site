# Русские описания для RU-версий товаров (замена румынского/английского текста поставщика)

Дата подготовки: 26.10.2026. Подготовил: content-agent.
Основание: аудит `docs/audit-ru-descriptions-in-romanian.md` — у этих товаров в RU-версии поле «Описание» содержит сырой текст поставщика на румынском (в одном случае на английском).

На сайте ничего не изменено. Это готовые тексты для ручной вставки.

## Как вставлять

1. wp-admin → Товары → найти товар по ID (поиск в списке товаров или ссылка вида `https://casa24.md/wp-admin/post.php?post=ID&action=edit`).
2. Убедиться, что открыта **RU-версия** товара (переключатель языка WPML в верхней панели / блок «Язык» справа). **RO-версию не трогать.**
3. В редакторе описания переключиться на вкладку **«Текст»** (не «Визуально»).
4. Полностью заменить содержимое поля описания HTML-блоком из этого файла.
5. Нажать **«Обновить»**, открыть товар на сайте и проверить, что текст отображается нормально.
6. Отметить ID как выполненный в этом файле (или в changelog `docs/priorities.md`).

Ссылки вида `https://casa24.md/?post_type=product&p=ID` — короткие ссылки по ID, они перенаправляют на карточку товара. Где известен полный URL — указан он.

Перед массовой вставкой — пройти раздел «Требует решения владельца» в конце файла: часть пунктов (помпоны, R10, стремянка, шуруповёрт) лучше решить до публикации.
