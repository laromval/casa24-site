## Как пользоваться этим файлом

При взятии задачи в работу — сменить статус на `in-progress` и указать ветку в git (`feature/...`/`fix/...`). После прохождения проверки qa-agent — `review` → `done`. Новые находки (не из исходного аудита) добавлять в конец соответствующего приоритета, не смешивая с P0 без веской причины.
