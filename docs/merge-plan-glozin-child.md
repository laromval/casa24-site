## Конфликты с нашей темой

- Пересечений имён PHP-функций нет — проверено.
- Хэндл стиля `glozin-child-style` есть в обеих темах. У подрядчика стиль
  родителя грузит сама Glozin; наш `functions.php` дополнительно подключает
  `glozin/style.css` как `glozin-style` — при слиянии это **убрать**, иначе
  родительский CSS загрузится дважды.
- Наш шаблон главной вызывает `get_header()` и затем выводит свою шапку —
  на живом сайте получатся две шапки. Решение: новую шапку переносить в
  `inc/header/main.php` подрядчика (или в шаблоны, которые он вызывает), а
  из шаблона главной её разметку убрать.

## План слияния (порядок)

**Шаги 1–3 выполнены 25.10.2026**, шаг 4 решён проще: на странице Industrial Pro
шапка/футер Glozin скрываются CSS по классу `ip-page`, `inc/header/main.php`
подрядчика не изменён. Встраивание новой шапки во весь сайт — позже, вместе с
редизайном остальных страниц. Новые стили грузятся только на этой странице.

1. За основу берём тему подрядчика `glozin-child` как есть — она рабочая.
2. Добавляем в неё наши файлы: `assets/*`, `template-homepage-industrial-pro.php`,
   стили Industrial Pro — отдельным файлом `assets/industrial-pro.css`,
   а не дописывая в их `style.css` (проще откатить).
3. В их `functions.php` дописываем в конец наши функции (шрифты, скрипты,
   меню, переключатель языка, отключение `wp-sitemap-users`), без подключения
   родительского стиля.
4. Шапку: новую разметку встраиваем в `inc/header/main.php`, проверяем поиск
   по штрихкоду, корзину, избранное, переключение языка.
5. Выкладываем **сначала на staging** (`public_html/staging.casa24.md` уже
   существует, создан 27.09.2026 — проверить, рабочая ли это копия и свежая ли).
6. Проверка qa-agent: чекаут до шага оплаты maib, ЛК, поиск по штрихкоду,
   RU/RO, мобильная версия.
