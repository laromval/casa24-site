# Фото товаров с телефона — компьютер в магазине

Инструкция для сессии Claude на компьютере в магазине. Составлена 30.10.2026 на домашнем компьютере владельца, перед тем как работа с фото переехала в магазин. Читать целиком перед первой работой. Здесь же правила владельца: память Claude с домашнего компьютера сюда не переносится.

## Как это работает

- Владелец ходит по магазину с телефоном. В приложении Claude на телефоне он открывает **эту сессию на компьютере в магазине** (удалённое управление, Remote Control) и пишет, например, «начинаем редактировать фотографии».
- Claude работает на этом компьютере: собирает партию товаров, запускает страницу проверки фото и открывает её в интернет через туннель Cloudflare. Владельцу в чат уходит ссылка с секретным ключом.
- На телефоне владелец открывает ссылку и жмёт **фотоаппарат** на карточке товара. Сразу открывается камера, снимок уходит в карточку: первый становится новым главным фото на белом квадрате, следующие идут в доп. фото. Остальные функции те же, что на компьютере: утвердить, кадрировать, повернуть, «Найти в Google», «Поручить Claude», «Сохранить решения».
- После «Сохранить решения» Claude сразу заливает утверждённые фото на casa24.md. Отдельной команды в чате не ждать.
- Компьютер должен быть включён и не засыпать (`mcp__ccd_host__request_keep_awake` на время работы).

Товары без фото с 30.10.2026 скрыты с витрины mu-plugin'ом `wp-content/mu-plugins/casa24-hide-no-photo.php`. Как только фото залито, товар появляется на сайте сам.

## Разовая настройка компьютера

Делать по одному шагу. Владельцу давать только то, что может сделать лишь он: пароли, вход в чужие сервисы, решения.

1. **Программы** (winget; каждую установку подтверждает владелец):
   - `winget install Git.Git Python.Python.3.12 OpenJS.NodeJS.LTS Cloudflare.cloudflared`
   - `python -m pip install pillow numpy`. Модель «Удалить фон» (`tools/media/.venv`, rembg/onnxruntime, ~7 ГБ памяти) на этом компьютере не ставить без просьбы владельца: кнопка без неё просто вернёт ошибку.
2. **Репозиторий:** `git clone https://github.com/laromval/casa24-site.git`, затем `git checkout feature/catalog-structure` (код фото на этой ветке; на 30.10.2026 в `dev`/`main` его ещё нет). Вход в GitHub — владелец.
3. **SSH-ключ к хостингу.** Без него нет заливки и WP-CLI. Два варианта:
   - **флешка:** владелец копирует с домашнего компьютера `~/.ssh/casa24_tophost` и `casa24_tophost.pub` в `~/.ssh/` этого компьютера;
   - **новый ключ:** `ssh-keygen -t ed25519 -f ~/.ssh/casa24_tophost -N ""`, затем владелец добавляет `.pub` в cPanel → SSH Access → Import Key → Authorize. Это одно из немногих мест, где cPanel делает сам владелец.
   - Проверка: `ssh -i ~/.ssh/casa24_tophost -p 49786 -o BatchMode=yes casamd@195.178.106.95 'cd ~/public_html && wp option get home'` → `https://casa24.md`.
4. **`.env` в корне репозитория** (в git не попадает, в чат не пересылать). Нужны три строки: `WP_URL=https://casa24.md`, `WP_APP_USER=…`, `WP_APP_PASSWORD=…`. Либо файл с флешки, либо владелец создаёт новый пароль приложения: wp-admin → Пользователи → Профиль → Пароли приложений.
5. **Удалённое управление:** включить Remote Control для этой сессии (`mcp__ccd_session_mgmt__set_remote_control` или настройки приложения). Владелец находит сессию в приложении Claude на телефоне.

## «Начинаем редактировать фотографии»

1. **Партия:** `python tools/media/make_batch.py batch-N 100`. Первыми идут товары **в наличии, но без фото**: список берётся с сайта по SSH, и пока они не кончились, партия состоит только из них. Затем идут товары с плохим фото из `tools/media/audit.json`. Этого файла в git нет: на новом компьютере его заново делает `photo_bg_audit.py`.
2. **Ключ:** `python -c "import secrets; print(secrets.token_urlsafe(16))"`. Он живёт одну рабочую сессию.
3. **Страница проверки** (в фоне): `python tools/media/review_server.py tools/media/batch-N <порт> --key <ключ>`. Порт свободный, например 4178. Без `--key` страница открывается только на этом компьютере. С телефона без ключа сервер отвечает 403, открыть Chrome на компьютере с телефона тоже нельзя.
4. **Туннель** (в фоне): `cloudflared tunnel --url http://localhost:<порт>`. В его выводе есть адрес `https://….trycloudflare.com`. Владельцу отправить одну ссылку: `https://….trycloudflare.com/?key=<ключ>`. При повторных открытиях ключ не нужен, его запоминает cookie на 30 дней. Адрес туннеля меняется при каждом запуске.
5. **Ждать решений:** держать Monitor на изменение `tools/media/batch-N/decisions.json` (опрос раз в 2 с, таймаут 30 мин, перевзводить). По событию: прочитать решения, бегло посмотреть утверждённые фото, выполнить `python tools/media/upload_batch.py tools/media/batch-N`, проверить 2–3 карточки на сайте (RU и RO), коротко отчитаться в чат. Товары с пометкой «Поручить Claude» (action "search") искать самому, см. правила ниже.
6. **В конце работы:** остановить туннель и сервер. Ссылка после этого перестаёт работать, и это нормально.

## Правила владельца (перенесены из памяти домашнего компьютера)

- **Сайт правится сразу на casa24.md**, staging не используется. Перед перезаписью файла на сервере сверить его с git (md5), положить копию в `~/backup-prod-<тема>-<дата>/`, после выкладки сделать `php -l` и сброс кэша `wp eval 'do_action("litespeed_purge_all");'`.
- **SSH-подключения объединять:** скрипт через scp и один ssh. 29.10.2026 после ~40 подключений подряд защита TopHost заблокировала IP, снимали тикетом.
- Всё, что можно, делать самому через SSH/WP-CLI. Владельца в cPanel/wp-admin не посылать, кроме паролей и того, что умеет только он. В панелях давать по одному шагу и ждать ответа.
- **Фото:** заливать только то, что владелец утвердил галочкой. Главное фото на белом квадрате 1000×1000, второе можно в интерьере. Не меньше ~800 px, без нарисованных чужих размеров, логотипов и рекламных надписей. Замок `casa24_photo_lock` (ставит `upload_batch.py`) защищает фото от обмена с 1С. Старые фото удаляет только владелец (`--purge-old`). Платные генераторы картинок не использовать.
- **Надписи на фото:** текст на самом товаре оставить; полосу с текстом над/под товаром обрезать; плашку в углу на однотонном фоне закрасить цветом фона; текст поверх товара сам не убирать, а показать владельцу.
- **Тексты на румынском** — молдавская лексика (`docs/glossary-ro-md.md`). RO-переводы Claude делает сам и ставит сразу на сайт.
- **Персональные данные клиентов** — по ужесточённым правилам с 27.10.2026, в git и чат не попадают.
- **Секреты** (ключ, `.env`, пароли) никогда не коммитить и не пересылать в чат — `docs/security-notes.md`.

## Если что-то не работает

- **Ссылка не открывается на телефоне:** туннель упал или компьютер уснул. Перезапустить `cloudflared` и прислать новую ссылку.
- **Камера не открывается, а предлагает выбрать файл:** так ведёт себя браузер на компьютере, на телефоне это норма. Если и на телефоне камера не открывается, у браузера нет разрешения на камеру: Chrome → Настройки сайтов → Камера.
- **403 на телефоне:** открыть ссылку именно с `?key=…`. Ключ меняется при каждом перезапуске сервера.
- **Ошибка заливки с 401:** `.env` устарел, нужен новый пароль приложения (шаг 4 настройки).
